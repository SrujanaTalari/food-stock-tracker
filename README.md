# 🍎 Food Stock Tracker

A simple and interactive Food Stock Tracker built using HTML, CSS, JavaScript, and Java.  
This project helps users manage food inventory, update stock levels, and receive low-stock alerts in real time.

## ✨ Features
- Add and update food items
- Low stock alert system
- Dynamic inventory table
- Responsive and clean UI

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- Java
